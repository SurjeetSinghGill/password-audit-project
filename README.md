# Password Audit & Hash Cracking Project

## Overview
This project simulates a post-breach password audit scenario where leaked password hashes are analyzed and cracked using offensive security tools.

The objective is to:
- Simulate breached password databases
- Generate multiple hash formats
- Crack weak passwords
- Analyze password policy weaknesses
- Demonstrate password auditing techniques used in cybersecurity

## Tools Used
- Kali Linux
- Python 3
- Hashcat
- John the Ripper
- RockYou Wordlist
- Git & GitHub

## Hash Types
- MD5
- SHA1
- SHA256
- NTLM

## Project Structure
- `hashes/` → generated hashes
- `wordlists/` → custom and rockyou wordlists
- `results/` → cracked passwords
- `scripts/` → automation scripts
- `report/` → audit findings
- `screenshots/` → evidence screenshots
